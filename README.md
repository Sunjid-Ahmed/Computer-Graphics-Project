## 📖 About the Project

**Daffodil Smart City Visualization** is an interactive **2D Computer Graphics** project developed using **C++, OpenGL, and FreeGLUT**. The project creates a digital representation of the **Daffodil International University (DIU) campus**, combining graphical primitives, geometric transformations, real-time animation, and keyboard-based interaction.

The virtual campus environment includes the **DIU building, roads, footpaths, trees, street lights, students, vehicles, clouds, rain, and a cricket ground**. Several interactive and animated elements are included to make the visualization more dynamic and engaging.

Users can control selected students, cricket players, and a car, move and zoom the camera, switch between **day and night modes**, enable rain effects, and interact with the cricket bowling and batting animation.

The project demonstrates practical applications of **2D object modeling, coordinate-based animation, translation, scaling, parametric circle and ellipse construction, event handling, and real-time rendering** using OpenGL.

## 🎮 Interaction & Animation

The application provides keyboard-based interaction for controlling different objects and navigating the scene.

The animation system uses a timer callback that updates approximately every **16 milliseconds**, allowing continuous movement of objects such as:

* Clouds
* Birds
* Students
* Rain
* Cricket ball
* Vehicles

The cricket section also supports bowling and batting interaction, where the cricket ball moves from the bowler toward the batsman and can be hit toward a target position.
